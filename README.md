# ゴルフスイング診断ツール（野山理論版）

スイング動画をアップロードすると、骨格を自動検出してスイングを採点し、
項目ごとの診断コメントと練習ドリルを表示します。

処理はすべてブラウザの中で完結します。動画がサーバーに送られることはありません。

## 使い方

1. デスクトップの **「ゴルフスイング診断ツール」** アイコンをダブルクリック
   （または `index.html` をブラウザで直接開く）
2. 利き手・カメラ位置・**使用クラブ**を選ぶ
3. **動画** または **ポジションごとの写真** を読み込んで「解析する」

初回だけ骨格検出モデル（約 6MB）をダウンロードするため、**インターネット接続が必要**です。
モデルの読み込みを含めて、最初の解析は 20 秒前後かかります。2 回目以降は速くなります。

### スマホでも使えます

パソコンと同じ画面がそのまま使えます（画面幅 320px から確認済み）。

- スマホでは **「カメラでスイングを撮る」** ボタンが出ます。押すとカメラが開き、
  撮った動画がそのまま取り込まれます
- 「動画ファイルを選ぶ」からでも、端末の写真アプリに保存済みのスイング動画を選べます
- 縦向き（9:16）で撮った動画にも対応しています

**スマホでは解析に時間がかかります。** パソコンより計算力が低いので、骨格検出のモデルを
1 段軽いものに自動で切り替えています（この道具が見ている体の位置や角度には十分な精度です）。
それでもパソコンの数倍かかるので、画面を閉じずにお待ちください。

### 入力方法は 2 通り

**動画から解析** — アドレスからフィニッシュまでを 1 回撮った動画を読み込むと、
手元と腕の動きから 7 つのキーフレームを自動で割り出して診断します。全項目が対象です。

**ポジションごとの写真** — アドレス・トップ・インパクトなどの静止画を、
ポジションごとに入れて診断します。

- **アドレスの写真は必須**です。体格・頭幅・左右の向きの基準をここから決めているためです
- 他のポジションは入れたものだけ診断します。足りない分は「診断できなかった項目」として
  結果画面に一覧表示されます
- **スイングテンポは判定できません。** 時間差から求める項目のため、静止画では算出できません

### デスクトップのアイコンについて

 Chrome でこのフォルダの
`index.html` を開くように設定されています。アイコン画像はこのフォルダの `icon.ico` です。

- **このフォルダを移動・改名するとショートカットが切れます。**
  その場合はショートカットを右クリック →「プロパティ」でリンク先を直してください
- アイコンを変えたい場合は `icon.ico` を差し替えるか、
  ショートカットのプロパティ →「アイコンの変更」から指定してください

### 動画の撮り方

| 項目 | 目安 |
|---|---|
| 長さ | 90 秒まで。前に構え直しや素振りが入っていても構いません |
| 回数 | 本番のスイングは **1 回だけ**（2 回以上入っていると、速いほうが選ばれます） |
| 画角 | 足元から頭まで全身が入る |
| 明るさ | 明るい場所。背景は無地に近いほど精度が上がる |
| 位置 | **正面**（体の正面から）と **後方**（飛球線の後ろから）の 2 種類 |
| 撮り方 | 三脚などで固定する（手持ちで大きく動かすと、スイングの位置を誤検出します） |
| 向き | 縦でも横でも可。スマホは立てかけるか、誰かに固定して持ってもらう |

#### スイングの位置は自動で探します（手で指定もできます）

8 秒を超える動画では、まず動画全体を低いフレームレートで骨格検出にかけ、**手元が最も速く
動いた瞬間＝インパクト付近**を割り出して、その前後（2.5 秒前〜2.0 秒後）だけを本番の
骨格検出にかけます。実際に解析した区間は結果画面の上部に表示されます。

> 粗いスキャンにも骨格検出を使っています。画素の差分で代用すると、被写体が小さく背景が
> 木立のような映像では、**風で揺れる背景のほうが大きな変化**として検出され、まったく違う
> 時刻を指してしまうためです（実際の動画で確認済み）。

**自動判定がずれる場合は、手で範囲を指定してください。** 動画を読み込むと、プレーヤーの下に
範囲指定のボタンが出ます。

| ボタン | 動作 |
|---|---|
| ◀ 現在位置を開始に | 再生位置を解析の開始点にする（アドレスの少し前で押す） |
| 現在位置を終了に ▶ | 再生位置を解析の終了点にする（フィニッシュの少し後で押す） |
| 自動で探す | 自動検出を実行して、結果を範囲として設定する（解析前に確認できます） |
| 指定を消す | 自動判定に戻す |

自動判定が外れやすいのは次のような動画です。手での指定をおすすめします。

- 本番のスイングが 2 回以上入っている（素振りではなく本打ちが複数回）
- 手持ち撮影でカメラが大きく動いている
- 画面を横切って歩く、他の人が写り込むなど、スイング以外の大きな動きがある

#### キーフレームはあとから 1 コマずつ直せます

結果画面の各ポジションの画像の下に **◀◀ ◀ ▶ ▶▶** ボタンがあります（動画モードのみ）。
押すとそのポジションを 1 コマ／5 コマ単位でずらせて、**スコアと診断がその場で再計算**されます。

アドレスは体格・頭幅・左右の向きの基準なので、ここを直すと全項目の数値が変わります。

正面と後方で測れる項目が違うので、両方の角度で撮って、それぞれ診断してください。

## 自動計測できること・できないこと

骨格検出は**人体の 33 点だけを認識し、クラブは認識しません**。
そのため、この 2 つに分けています。

### 結果はポジションごとにまとまっています

結果画面は **アドレス / テークバック / バックスイング / トップ / ダウンスイング / インパクト / フォロー /
フィニッシュ / スイング全体** の順にカードが並び、各カードの中に

- **そのポジションの総評**（カードのいちばん上）。「4 項目すべてが基準内です」
  「3 項目のうち 1 項目が基準を外れています。まずは『〜』から直してください」のように、
  項目を上から読まなくても、そのポジションの出来と直す順番が分かります。
  点数から自動で作るので、文言の調整は不要です（左の縦線が緑／黄／赤で色分けされます）。
  同じ総評を、動画の横（スマホでは動画の下）の注意点の先頭にも出します
- **そのポジションのコマの画像**（骨格つき、◀◀ ◀ ▶ ▶▶ でコマ送り調整）。
  骨格の位置から**スイングしている人だけを切り出して拡大**します（実測で 2.5 倍前後）。
  クラブは検出できないので、体の大きさに応じた余白を上下左右に足しています。
  切り出す範囲は全ポジション共通です — ポジションごとに変えると人の大きさも位置も
  変わってしまい、姿勢の移り変わりが読み取れなくなるためです
- そのポジションの**計測した診断**とドリル
- そのポジションの**目視チェック項目**

がまとまっています。どの説明がどの姿勢の話なのかが、画像と並べて確認できます。

### 赤いガイド線とスロー再生

動画とポジション画像に、赤いガイド線を重ねます。**再生速度は 1/8・1/4・1/2・等倍**から
選べ、スローで流しながら線とのズレを追えます。線が邪魔なときは「赤い線を出す」を外します。

**診断が終わると、赤い線を入れたまま 0.5 倍速で 1 回自動再生し、終わったらアドレスで
止まります。** 流すのは**アドレスからフィニッシュまで**だけで、構え直しや振り終わったあとの
動きは入りません。

画面の並びは幅で変わります。**広い画面**は左に「動画・ポジションのボタン・操作」、
右に「注意点」の 2 列。**スマホ**は上から**動画 → 注意点 → ポジションのボタン → 操作**
の 1 列で、コメント付きスローのときに動画のすぐ下でコメントが読めます。
どちらも横スクロールは出ません。

| ボタン | 動作 |
|---|---|
| ▶ スローで見直す | アドレス〜フィニッシュを 0.5 倍速でもう一度流す |
| ▶ コメント付きスロー | 0.5 倍速で流しながら**各ポジションで止まり**、右側にそのポジションの注意点を出す。1 か所につき 8 秒（`app.js` の `TOUR_PAUSE`）。押している間は「止める」に変わり、いつでも中断できます |

| 撮影 | 引く線 |
|---|---|
| **正面** | 鼻を通る垂直線（頭の少し上から足元まで）。頭が左右に動いていないかを見ます |
| **後方** | ①ボールと首の付け根を結んだ線 ②シャフトのライン ③背中の後ろの線 |

後方の ①② はボールで交わり、上へ向かって少しずつ開きます。この 2 本の間をヘッドが
通っていれば、スイングプレーンに乗っています。③ は背骨と平行に、お腹の厚みの半分だけ
後ろへずらした線で、**頭の少し上からお尻の少し下まで**引きます（地面まで伸ばすと
脚に重なって背中の向きが読み取りにくくなるため）。

**線はアドレスの骨格から 1 回だけ引いて、そのまま固定します。** スイング中の骨格に
追わせると線が体と一緒に動いてしまい、クラブがその線をどう通ったかが読めなくなるためです。

#### 線は手で直せます・足せます・消せます

骨格検出のズレで線が合わないことがあるので、あとから動かせるようにしています。

| ボタン | 動作 |
|---|---|
| 線を動かす | 線をつまめる状態にする（動画は止まります）。もう一度押すと戻ります |
| 線を足す | 画面の真ん中に新しい線を 1 本足す（最大 8 本） |
| 選んだ線を消す | 選んでいる線（オレンジ色）を消す |
| 最初に戻す | 骨格から引き直す |

線の**端（●）をつまむとその端だけ**、**線の途中をつまむと線ごと**動きます。
「線を動かす」を解除したときに、各ポジションの画像も新しい線で描き直します。
線を動かす・足す・消すと画面下に**「修正した位置で診断し直す」**が出ます。
手で直した線は診断し直しても引き継ぎ、骨格から引き直したいときは「最初に戻す」を押します。

**シャフトとボールはクラブ側なので検出できません。** ボールの位置は「手元からクラブの
ライ角（1W 56°／FW・UT 57°／アイアン 61°／ウエッジ 64°）で地面まで下ろした先」として
求めた推定値です。ズレていたら線を手で直すか、毎回同じだけズレるようなら
`analyzer.js` の `LIE_ANGLE` を調整してください。

### 動画をポジションで止めて注意点を読めます

解析後も結果画面の上部に**動画プレーヤーが残る**ので、そのままスイングを見返せます。
プレーヤーの下にポジションのボタンが並び、

- **ボタンを押す** … その位置で動画が止まり、下にそのポジションの注意点が出ます
- **動画を手で止める・シークする** … いちばん近いポジション（0.5 秒以内）の注意点に
  自動で切り替わります。どのポジションからも離れているときは、ボタンの選択だけ外れます
- **下の各ポジションの画像をクリック** … 同じように動画がそこで止まり、注意点が出ます

注意点は、**基準を外れたものから順に**（点数の低い順に）並びます。計測項目は判定・数値・
目安・コメント、目視チェックは文言が出ます。練習ドリルはここには出さず、下のポジション
カードにまとめています（同じ内容が 2 か所に長く出るのを避けるため）。

**クラブごとのアドレスの目安**（ボール位置・スタンス幅・前傾角・重心・手元）は、
アドレスのカードの先頭に出ます。以前は独立した「アドレス基準」カードにしていましたが、
すぐ下のアドレスの診断項目と画像・数値・判定がまるごと重複していたので 1 つにまとめました。
目安の表には言葉での基準だけを書き、数値と判定はその下の診断項目が担います。
撮った角度で確かめられる行だけを出し、残りはどちらから撮れば出るかを添えています。

**スイング全体の項目（テンポなど）は総合スコアの欄にまとめています。** ポジションごとの
カードにも「スイング全体」を作ると、同じ話が 2 か所に出てしまうためです。

#### 位置を直したら「診断し直す」

キーフレームを **◀◀ ◀ ▶ ▶▶** で動かすと、その画像だけが差し替わり、画面下に
**「修正した位置で診断し直す」** ボタンが出ます。押すとその位置でスコアと診断を計算し直します。

1 コマ動かすたびに全部を作り直すと、複数のポジションを直しているあいだ画面が落ち着かないので、
まとめて直してから 1 回押す形にしています。

### 基準を外れた項目には、参考レッスン動画が付きます

YouTube チャンネル **[ゴルフ力UPレッスン](https://www.youtube.com/@up7267)** から、その項目を
扱っている動画を表示します。サムネイルを押すとその場で再生できます（良好な項目には出ません）。

動画は**固定ではなく、そのつど検索して選びます。** チャンネルの全動画（916 本）のタイトルを
`videos.js` に持っておき、症状ごとのキーワードで毎回検索して、点数の高い順に候補を出します。
動画IDを直接書いていないので、**チャンネルに動画が増えれば自動的に候補も増えます**。

> ローカルの HTML から YouTube を直接検索することはできません。別ドメインへの通信が
> ブラウザに止められるためです（API キーを取れば可能ですが、設定の手間と利用回数の
> 制限があります）。そこで目録をローカルに持ち、そこを検索する形にしています。

**紹介するのは 1 回の診断につき 1 本だけ。** 「優先して直したい項目」のいちばん上に付きます。
たくさん出すと、どれを見ればいいのか分からなくなるためです。まず 1 つだけ直してください。
本数を変えたいときは `app.js` の `MAX_LESSONS` を書き換えてください。

**解析するたびに違う動画が出ます。** 1 症状につき最大 5 本を候補として持ち、前回どこまで
出したかをブラウザが覚えていて順に送ります。ランダムだと続けて同じものが出てしまうため、
候補を一巡してから最初に戻る方式です。

**ミスの向きによって検索語が変わります。** たとえばトップの腰の位置なら

- **右に流れている**（スウェー）→「スウェー」「軸ブレ」で検索
- **左に動いている**（腰が引ける）→「腰が引け」「腰が回らない」で検索

#### 出てくる動画を変えたいとき

検索語は `criteria.js` の `LESSON_QUERIES` にまとまっています。`['語', 重み]` の形で、
重みが大きいほど優先されます。症状に合わない動画が出るときは、ここの言葉を調整してください。

```js
const LESSON_QUERIES = {
  spineAddress: { any: [['前傾角度', 4], ['前傾', 3], ['アドレス', 1]] },
  hipAtTop: {                                  // 向きによって検索語を変える
    high: [['スウェー', 5], ['スエー', 5], ['軸ブレ', 4]],
    low:  [['腰が引け', 5], ['腰が回らない', 4], ['引ける', 3]]
  }
};
```

検索は表記ゆれを吸収します（全角英数字・長音記号・空白）。複数の語が当たった動画ほど、
また題名が短い＝その話が主題である動画ほど上位に来ます。

**軽い語がかすっただけの動画は候補から外します。** いちばん良く当たった動画の半分に
届かないものは切り捨てます。たとえば「肩の回転不足」に対して「スイングの始動は肩から？
腰から？」のような、症状とずれた動画が出てしまうためです。
その結果、ぴったり合う動画が 1 本しかない症状もあります。その場合は毎回その 1 本が出ます。

#### 新しい動画を追加したとき

`videos.js`（目録）を作り直してください。**スクロールは不要**で、数十秒で終わります。

1. Chrome で [チャンネルの動画一覧](https://www.youtube.com/@up7267/videos) を開く
2. `F12` →「Console」タブ
3. `update-videos.js` の中身を全部コピーして貼り付け、Enter
4. ダウンロードされた `videos.js` を、このフォルダの `videos.js` に上書き

`node test.js` を実行すると、目録が壊れていないか、各症状で動画が見つかるかを確認できます。

### レッスンのご案内を最後に出します

結果画面のいちばん下に、顔写真（`noyama2.png`）と並べて、オンラインスイング診断・
ラウンドレッスン・ホームページへの案内を表示します。文言・URL・並び順は
`criteria.js` の `CONTACT_LINKS` で変更できます（配列の順にそのまま並びます）。

```js
const CONTACT_LINKS = [
  { url: 'https://noyamagolf.com/%e3%82%aa…/', title: 'オンラインスイング診断', lead: '…' },
  { url: 'https://noyamagolf.com/?p=47',       title: 'ラウンドレッスンのご案内', lead: '…' },
  { url: 'https://noyamagolf.com/',            title: '野山佳治 ホームページ',   lead: '…' }
];
```

オンラインレッスンの URL は日本語を含むのでパーセントエンコードしてあります
（デコードすると `https://noyamagolf.com/オンラインレッスン/`）。
料金の案内はこのツールには書いていません（変わったときに直し忘れるため）。
リンク先のページでご確認いただく形にしています。

### 数値は「＋−」ではなく言葉で出ます

重心や頭の位置のように向きのある数値は、`+0.08` ではなく **「右足寄り 0.08」** のように
どちら側かを言葉で表示します。目安の範囲も同じ形式です（例: 目安 右足寄り 0.03〜0.20）。

向きの言葉は `criteria.js` の `signLabels` で決めています。

```js
addressBalance: {
  signLabels: ['右足寄り', '左足寄り'],   // [プラスの意味, マイナスの意味]
  ideal: [-0.06, 0.07], …
}
```

### 自動計測（41 項目：正面 24 / 後方 20、うち両方で測るものが 3）

体の位置・角度・移動量から数値を出して採点します。

**アドレス**
| 項目 | カメラ | 基準 |
|---|---|---|
| 前傾角 | 後方 | 1W 30° / FW・UT 33° / アイアン 39° / ウエッジ 45° を中心に ± 4°（アイアンは 5番〜PW をまとめているので ± 6°） |
| スタンスの幅 | 正面 | 肩幅（1W は少し広く） |
| 左右バランス（重心配分の目安） | 正面 | 1W 右 6:4 / FW・UT・アイアン均等 / ウエッジ左 6:4 |
| **前後の重心** | 後方 | 足の中央〜ややつま先寄り |
| 手元位置（体のセンターよりやや左か） | 正面 | +0.02 〜 +0.16 |
| 手元位置（肩の真下か） | 後方 | 肩の真下（1W は少し前） |
| **手と体の距離** | 後方 | 拳 1.2〜2.3 個（**1W は 1.8〜3.4 個**） |
| 肩の傾き | 正面 | 右肩が 3〜14° 下がる |

**テークバック（シャフトが水平）**
| 項目 | カメラ | 基準 |
|---|---|---|
| **腰の位置（アドレス比）** | 正面 | 右へのスウェー・左への引けを判定 |
| **頭の移動量** | 正面 | ほぼ動かない（右へ 0.30 頭分まで） |
| **背骨の傾きと左前腕（肘〜手首）が平行か** | 後方 | 傾きの差 15° 以内（0° で平行）。**1W では出しません**（手元を体から離して構えるぶん前腕の向きが変わるため） |
| **テークバックでの前傾キープ** | 後方 | アドレスから 8° 以内 |

**バックスイング・トップ**
| 項目 | カメラ | 基準 |
|---|---|---|
| 左腕が水平のときの手元の位置 | 後方 | 右肩の真下あたり（前後のずれで判定） |
| 前傾のキープ | 後方 | アドレスから 8° 以内 |
| **トップで左腕が右肩を横切っているか** | 後方 | ボール側へ 0.15 まで |
| 肩の回転量 | 正面 | 80〜100° |
| 腰の位置（構えた位置で回れているか） | 正面 | 右へのスウェー・左への引けを判定 |
| 頭の移動量 | 正面 | 右に 0.1〜0.5 頭分（動かなさすぎも減点） |
| **トップでの頭の高さ（アドレス比）** | 共通 | 上下 0.10 以内 |
| **トップでのお尻の位置（ボールに近づいていないか）** | 後方 | ボール側へ 0.06 まで |

**ダウンスイング〜フィニッシュ**
| 項目 | カメラ | 基準 |
|---|---|---|
| 左腕が水平に戻ったときの腰の移動 | 正面 | トップより少し左へ |
| **ダウンでの前傾キープ** | 後方 | アドレスから 8° 以内（起き上がりを見ます） |
| **ダウンでのお尻の位置（お腹が前に出ていないか）** | 後方 | ボール側へ 0.05 まで |
| **ダウンでの頭の高さ（アドレス比）** | 後方 | 上に 0.08・下に 0.18 まで（沈むのは自然なので、起き上がり側だけ厳しく） |
| インパクトの前傾キープ | 後方 | アドレスから 8° 以内 |
| **インパクトのお尻の位置（お腹が前に出ていないか）** | 後方 | ボール側へ 0.05 まで |
| インパクトの頭の位置 | 正面 | 通常は構えた位置／**1W は少し右** |
| インパクトの腰の位置 | 正面 | 構えた位置より少し左 |
| インパクトの左足の垂直性 | 正面 | 垂直まで（目標方向に傾くと左スウェー） |
| **右腕が水平のときの前傾（アドレス比）** | 後方 | 16° 以内（起き上がっていく途中なので他より緩め） |
| 右腕が水平のときの右肘の伸び | 正面 | 150° 以上（後方からは腕が重なって見えるため測りません） |
| 右腕が水平のときの腰の位置 | 正面 | 目標方向に移動済み |
| フィニッシュの垂直性（左足〜右腰〜右肩） | 正面 | 8° 以内 |

| フィニッシュの右足の垂直性（**かかと〜つま先**） | 共通 | 垂直から 30° 以内 |
| スイングテンポ（補助項目） | 共通 | 1.8〜4.2 : 1（ツアー基準 3:1 に測定誤差 ±20% を見込んだ幅。元の秒数も表示） |

### 目視チェックリスト（9 項目）

**クラブが関わる項目は自動計測できません。** 各ポジションのカードの中に、
その画像と並べてチェックリストが出ます。

- ボールの位置（**アドレス画像に、そのクラブの正しいボール位置を緑の帯で描きます**。
  ボール自体は小さすぎてティーや靴と紛れるため検出していません。アイアンは 5番〜PW を
  ひとまとめにしているので、帯は「中央〜左足かかとと中央の間」と広めになります）
- **バックスイング**（左腕が水平）: 左腕とクラブが直角か（**正面から**）/
  グリップエンドがターゲットラインを指しているか（後方から）
- トップでシャフトは水平か
- **ダウンスイング**: **アウトサイドインになっていないか**（原因: 肩が回っていない・
  切り返しのタイミングが早い）/ **インサイドから降りすぎていないか**（原因: 前傾が起きている・
  右足に体重が残っている）
- フィニッシュで右足の裏が全部見えるか / クラブが首筋に来ているか
- クラブヘッドの軌道がスイングプレーンの中を通っているか

スイングプレーンの目安線は、**赤いガイド線**として動画と全ポジションの画像に重ねます
（「赤いガイド線とスロー再生」を参照）。

### 数値の読み方

- **体格比** … アドレス時の「腰の中心〜肩の中心」の長さを 1.0 とした相対値
- **頭幅比** … アドレス時の「両耳の間隔」を 1.0 とした相対値（**0.5 = 頭半分**）
- 符号はすべて右打ちに換算済み。左打ちでも同じ基準で読めます

身長や撮影距離で割った相対値なので、誰が撮っても同じ基準で比較できます。

## 診断基準を変更する

**`criteria.js` だけ**を編集してください。解析エンジン（`analyzer.js`）は触る必要がありません。

```js
{
  id: 'headAtImpact',
  phase: 'impact',              // 画面のグループ分けに使う
  label: 'インパクトでの頭の位置（アドレス比）',
  view: 'front',                // 'front' 正面 / 'side' 後方 / 'both' 共通
  unit: '頭幅比',
  dir: 'プラス = アドレスより右 / マイナス = 左',
  ideal: [-0.15, 0.20],         // この範囲なら 100 点
  hard:  [-0.85, 0.95],         // この範囲を外れると 0 点
  weight: 1.4,                  // 総合スコアへの寄与度
  good: '基準内のときのコメント',
  high: '上限を超えたときのコメント',
  low:  '下限を下回ったときのコメント',
  drill: '改善ドリル',

  byClub: {                     // 番手ごとの上書き（指定した項目だけ差し替わる）
    driver: { ideal: [0.15, 0.75], hard: [-0.45, 1.45], low: 'ドライバー用のコメント' }
  }
}
```

- 番手ごとの基準表は `CLUBS`、目視チェックリストは `VISUAL_CHECKS`、
  総合スコアの講評は `OVERALL_COMMENTS` で変更できます
- 項目の追加・削除も自由です。ただし新しい `id` を足す場合は、
  その値を計算する処理を `analyzer.js` の `measure()` に書き加える必要があります

## 動作確認

`criteria.js` を編集したら、合成データによる自動テストで壊れていないか確認できます。

```bash
node test.js
```

1005 項目を検証します。キーフレーム検出の正しさ、**縦で撮っても横で撮っても同じ数値になること**、
クラブによって出す・出さないが変わる項目、
赤いガイド線の位置、左右反転の対称性、番手ごとの基準の
切り替え、採点の境界値、基準の整合性（`hard ⊇ ideal` など）、計測漏れの検出、
写真モード（ポジションが一部だけのケース）、スイング前にワッグルや素振りが入っている動画、
骨格検出が 1 コマだけ乱れたケース、手首の検出が毎コマ揺れるケース、動画目録の健全性、症状ごとの検索（各症状で動画が見つかること・候補を一巡すること・連続して同じ動画が出ないこと）、向きのある数値に言葉のラベルが付いていること、`app.js` が `id` で引く要素が `index.html` に実在すること（書き忘れると結果表示のときに初めて落ちるため）を含みます。

実際のスイング動画を解析して分かった、テストに落としてある注意点が 2 つあります。

- **`visibility` でコマを捨ててはいけない。** 手が速く動くバックスイング〜フィニッシュでは
  `visibility` が 0.01〜0.46 まで下がるため、「はっきり写っていないコマを除く」と
  肝心のスイングが丸ごと落ちます
- **キーフレームは手元の「速度」ではなく「高さ」で決める。** 被写体が画面内で小さいと
  手首の検出が数ピクセル揺れ、その見かけの速度が実際のインパクトと同じか、それ以上に
  なります（実測: インパクト 0.056 に対し、フィニッシュで手が頭に重なるあたりの揺れが
  0.081）。骨格検出は実行のたびに結果が微妙に変わるため、どちらが勝つかも安定しません。
  手元の高さはアドレスからトップまで画面の 3 割ほど動くので揺れに埋もれず、
  実際の動画で 2 回続けて解析してもトップ・インパクトが 1 コマも動きませんでした
- **トップは「手元が高い最初のかたまり」から探す。** 全体の最小値をそのまま採ると、
  フィニッシュで手がトップと同じ高さまで上がる人ではフィニッシュをトップと取り違えます
- **「腕が水平」は区間内で最も水平に近いコマではなく、最初に肩の高さを越える瞬間で取る。**
  フィニッシュで腕をたたんだ姿勢は、肘が深く曲がっていても肩と手首の高さがそろうため、
  そこを拾うと「チキンウィング」と誤判定します
- **フィニッシュの右足は「かかと〜つま先」で測る。すね（膝→足首）ではない。**
  フルフィニッシュでは足を後ろに残したままつま先立ちになるので、すねは 30° ほど傾いていても
  足自体は地面と垂直です。すねを測ると、正しく振り切れているのに減点されます

## 精度についての注意

2 次元の映像からの推定です。特に以下は目安としてお読みください。

**映像の縦横比について。** 骨格の座標は x が「幅の何割」、y が「高さの何割」で返ってきます。
そのまま使うと、同じ姿勢でも縦で撮るか横で撮るかで数値が変わってしまいます
（実測で、同じ姿勢の手と体の距離が 16:9 で 0.91 拳・9:16 で 3.05 拳・1:1 で 2.03 拳）。
コマを取り出す時点で x を高さ基準にそろえているので、どの向きで撮っても同じ数値になります。
`node test.js` の「4-4」でこれを検証しています。

- **肩の回転量** … 正面から見た肩幅の縮み具合から逆算しています。カメラの高さや
  立ち位置がずれると誤差が出ます
- **アドレスの左右バランス** … 実際の荷重ではなく、上体の左右位置からの推定です
- **スタンスの幅** … 肩の関節位置を基準にした比率です。実際の「肩幅スタンス」の
  感覚と数値がずれる場合は、`criteria.js` の `stanceWidth` を調整してください
- **手と体の距離** … 腰の中心から「お腹の厚みの半分（0.23 × 胴の長さ）」だけ前を体の前面と
  みなし、そこから手元までを拳の幅（頭幅 15cm の 0.55 倍 ＝ 8.5cm、頭幅は 0.35 × 胴の長さ）で
  割っています。前傾 38°・手元が肩の真下なら拳 2.0 個分になる換算です。
  **以前は膝を基準にしていましたが、膝はアドレスで手元とほぼ同じ前後位置に来るため、
  実際は離れているのに「近すぎる」と出ていました。** 実際の拳の数と合わない場合は
  `analyzer.js` の `bodyHalfDepth` か `criteria.js` の `handDistance` を調整してください
- **前後の重心** … 実際の荷重ではなく、腰の中心が足首とつま先の中間からどちら側にあるかで
  推定しています。カメラの高さで数値が変わるので `weightFrontBack` を調整してください

「切り返しで下半身が先に動いているか」「インパクトの腰の開き」も数値化を試しましたが、
前者は肩の中心が切り返しでほとんど横に動かないため動き出しの時刻が安定して拾えず、
後者は肩が真横を向きかけていると比が跳ね上がって値が信用できないため、どちらも入れて
いません。下半身から切り返せているかは「左腕が水平に戻ったときの腰の移動」（`hipDownswing`）
で見てください。

ファイルを編集しても画面が変わらないときは、ブラウザで `Ctrl` + `F5`（強制再読み込み）を
お試しください。
